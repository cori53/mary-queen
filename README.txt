COME AGGIORNARE L'APP GITHUB:
1. Decomprimi questo ZIP.
2. Carica TUTTI i file e la cartella assets nel repository mary-queen.
3. Sostituisci i vecchi file.
4. Fai Commit changes.
5. Attendi GitHub Pages 2–5 minuti e riapri l'app.
6. Se l'app installata mostra ancora la vecchia versione, chiudila e riaprila; in casi ostinati disinstallala e reinstallala.

LIMITI REALI:
- Non c'è ancora un backend/account cloud: login e dati sono locali.
- Vicino a Te usa una ricerca esterna su Google Maps; non c'è un database proprietario di professionisti.
- AI/medicina: l'app organizza dati e routine, non sostituisce professionisti.
